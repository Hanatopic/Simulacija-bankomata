# C++ Simulacija bankomata
Projekat urađen kao vježba za utvrđivanje principa objektno-orijentisanog programiranja. 
## Osnovne funkcionalnosti
- Pregled stanja računa i osnovnih podataka vlasnika računa,
- Mogućnost uplate i isplate sredstava na račun, te provjera raspoloživih sredstava i validacija unosa,
- Prikaz historije svih transakcija.
